
# ByteBuddy 🤖

**ByteBuddy** is an intelligent AI Chatbot application built with Python and Streamlit. It provides a seamless, interactive interface for conversations powered by open-source language models from Hugging Face.

## Features ✨

- 💬 **Real-time Chat Interface** - Interactive chat with message history
- 🤖 **AI-Powered Responses** - Powered by open-source models from Hugging Face
- ⚙️ **Customizable Settings**
  - Multiple model selection (Mistral, Llama 2, Zephyr, Falcon)
  - Temperature adjustment (creativity level)
  - Max token control
  - Top P diversity sampling
- 💾 **Conversation History** - Maintains chat context across interactions
- 🎨 **Modern UI** - Clean and intuitive Streamlit interface
- 🔒 **Secure Token Management** - Password-protected Hugging Face token input
- 💰 **Free to Use** - No API costs with Hugging Face free tier

## Prerequisites 📋

- Python 3.8 or higher
- Hugging Face API token (get one from [Hugging Face](https://huggingface.co/settings/tokens))
- pip (Python package manager)
